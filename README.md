# cppchessbot

This is my attempt to write a chess engine in C++ from scratch. Inspired by [this Project](https://github.com/kevlu8/PZChessBot) by [kevlu8](https://github.com/kevlu8)

Currently i am working on getting the engine better than me (~1500 on lichess) without using any external resources dedicated to chess programming (e.g. Chess Programming Wiki) and without the help of AI coding assistance. 

[Play against the bot (if up)](https://lichess.org/@/cppchessbot)
